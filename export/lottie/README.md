# ZhareHub profile loader — Lottie

All files: 120×120, 60 fps, transparent, looping. Place the 96px avatar centred on top.

- pulse-light/dark.json — 2 s loop. Two orange rings (96px) scale 100→170% and fade 45→0%, offset by 1 s. Ease cubic-bezier(0.2, 0.6, 0.4, 1).
- stroke-loader-light/dark.json — 1.1 s loop. 3px track ring (112px) with a 28% primary-blue arc rotating 360° linearly.

Colors: Orange #FF8D28 / #FF9230 · Primary #226DB4 / #2F80CC · Track rgba(120,120,128,.16) / .32
